# Build TrollPadOS 4.0.0 on GitHub

1. Put this repository on GitHub with the exact path `.github/workflows/build.yml`.
2. Open **Actions**.
3. Select **Build TrollPadOS deb**.
4. Click **Run workflow** on the `main` branch.
5. When the job is green, open **Artifacts**.
6. Download `TrollPadOS-debs`.

The artifact contains both rootless and rootful packages.
